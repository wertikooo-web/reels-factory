# Reels Factory

MVP: turn a long YouTube video into ranked short-form clip candidates.

## MVP flow

1. Paste a YouTube URL.
2. Fetch timestamped transcript.
3. Analyze transcript and rank short-form candidates.
4. Return 10 clips with start/end timestamps, hook, title, reason and score.
5. Later: cut source video, reframe to 9:16, subtitles and MP4 export.
